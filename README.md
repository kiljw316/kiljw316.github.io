# kiljw316.github.io

## `_posts` 글 작성 형식

- 파일명은 YYYY-MM-DD-title.md
- 각 글 상단에 front matter 붙이기

```markdown
---
layout: post
title: "GitHub Pages 블로그 구조 정리"
date: 2026-07-07
categories: github-pages
tags: [GitHub, blog, jekyll]
---
```

## 폴더 구조

    - engineering/ # 백엔드, DB, 인프라 기술 글
    - field-notes/ # 현업 문제 해결 기록
